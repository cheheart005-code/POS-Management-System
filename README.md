# 🧾 POS Management System

A simple **Point of Sale (POS) Management System** built using HTML, CSS, and JavaScript.

This project was created to practice frontend web development and to understand how a basic POS system works, including products, inventory, checkout, and sales records.

## 📌 About the Project

The POS Management System allows a user to:

- Add products
- Set product prices
- Manage product stock
- Restock products
- Add products to a cart
- Calculate the total price
- Checkout products
- Record sales
- View transaction history
- View inventory
- View basic sales information through a dashboard

## 🛠️ Technologies Used

- **HTML** – Structure of the system
- **CSS** – Styling and layout
- **JavaScript** – Functionality and calculations

## ✨ Main Features

### 🛒 Product Management
Add products and set their prices and available stock.

### 📦 Inventory Management
View available products and their stock levels. Products can also be restocked when stock is low.

### 💰 Checkout
Add products to the cart and calculate the total amount before completing a sale.

### 📋 Sales Records
Completed sales are recorded so that previous transactions can be viewed.

### 📊 Dashboard
Displays basic information about the POS system and sales.

## 📱 Interface

The system was designed with a simple and beginner-friendly interface that makes it easy to understand and use.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start using the POS system.
